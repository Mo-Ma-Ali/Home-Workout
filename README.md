# Home Workout

A workout application developed using Laravel.

The project provides a web application structure for managing workout-related content and data through a Laravel backend.

## Overview

The application was developed to explore full-stack web development using Laravel, including:

* Backend application development
* Database management
* Routing
* Application views
* Asset management
* Testing

## Technologies

* PHP
* Laravel
* MySQL
* Blade
* Vite
* PHPUnit
* Composer

## Project Structure

```text
Home-Workout/
├── app/
├── bootstrap/
├── config/
├── database/
├── public/
├── resources/
├── routes/
├── storage/
├── tests/
├── composer.json
├── package.json
└── vite.config.js
```

## Main Laravel Components

### Backend

The application logic is organized inside the Laravel `app` directory.

### Database

Database-related files and migrations are located in:

```text
database/
```

### Routes

Application routes are defined in:

```text
routes/
```

### Frontend

Frontend resources and assets are managed through:

```text
resources/
```

with Vite used for asset development.

### Testing

The project includes a testing structure under:

```text
tests/
```
